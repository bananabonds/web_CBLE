1. Classes of Differential Equations

Before solving a differential equation, name it. The order is the highest derivative that appears; the degree is the exponent of that highest derivative once the equation has been cleared of fractions in the derivatives. The distinction matters because a first-order equation of fourth degree is a fundamentally different object from a fourth-order equation of first degree, even though both are "fourths."

Order and degree

QuantityDefinition
Orderhighest derivative present
Degreeexponent of the highest derivative, after clearing fractional powers in the derivatives

Clearing a fractional power means raising both sides to the denominator's power, which raises the degree to a whole number. An equation written as (dy/dx)4/3 + … has degree 4 once both sides are cubed.

Families of curves and their differential equations

A one-parameter family F(x, y, C) = 0 has a first-order ODE obtained by differentiating once and eliminating C. A two-parameter family has a second-order ODE; an n-parameter family has an n-th order ODE. The procedure is mechanical: differentiate n times, then eliminate the n constants between the (n+1) equations (the original plus the n derivatives).

Orthogonal trajectories

If a family of curves satisfies y′ = f(x, y), the family of curves meeting every member at right angles satisfies

y′ = −1f(x, y)

because perpendicular slopes multiply to −1. The new equation is then solved for the orthogonal family. For a family given in terms of C rather than as an explicit y′, the first step is to eliminate C.

Systems of first-order equations

An n-th order ODE can be written as a system of n first-order equations by introducing new variables for the lower derivatives:

y1 = y, y2 = y′, y3 = y″, …, yn = y(n−1)

Then yi′ = yi+1 for i = 1 … n−1, and the original equation supplies yn′. In matrix form the system is

Y′ = A Y

with A the companion matrix of the original equation. The last row of A carries the coefficients of the original ODE with their signs reversed and in the reversed order: for y(n) + a1y(n−1) + … + any = 0, the last row is [−an, −an−1, …, −a1].

Worked 1.5: an ODE as a system of first-order equations

Consider y‴ + 4y″ − 5y′ + y = 0. Reduce it to a system of first-order equations.

Show solution
Step 1 — define new variables for the function and its lower derivatives
y1 = y, y2 = y′, y3 = y″
Step 2 — the first two equations are just the definitions
y1′ = y2
y2′ = y3
Step 3 — the original equation, rearranged for the highest derivative
y‴ = −y + 5y′ − 4y″
Step 4 — translate to the new variables
y3′ = −y1 + 5y2 − 4y3
y1′ = y2, y2′ = y3, y3′ = −y1 + 5y2 − 4y3
The answer with y1′ = y1 is not a translation of any third-order ODE — it would mean y′ = y, which is first order and has nothing to do with the given equation. Every definition yi′ = yi+1 is fixed by the chain of derivatives; the last equation is the only one where the coefficients of the original appear, with their signs reversed.
Variables y — the solution function y1, y2, y3 — the state variables

Eliminating constants

Differentiate the given solution n times and eliminate the n constants between the (n+1) equations. When the solution is a family of polynomials, exponentials or logarithms, the eliminant is usually a linear ODE with polynomial coefficients.

Cauchy–Euler equations

xn y(n) + a1 xn−1 y(n−1) + … + an y = 0

Substituting y = xm converts it to an algebraic equation in m. The three cases of roots (distinct real, repeated real, complex) each produce a solution form, exactly as for constant-coefficient equations, with xm replacing erx and ln x replacing x.

Worked 2.4: a homogeneous equation

Solve (y − √(x² + y²))dx − x dy = 0.

( vx − √(x² + v²x²) ) dx − x ( v dx + x dv ) = 0
Step 2 — simplify; the vx dx terms cancel and x factors out of the radical

3. Integrating Factors

An equation M dx + N dy = 0 is exact when My = Nx. When it is not, an integrating factor μ(x, y) turns it into an exact equation:

( μM )y = ( μN )x

Three standard routes produce μ.

μ depending on x alone

If (My − Nx)/N is a function of x only, then

μ( x ) = exp( ∫ My − NxN dx )

μ depending on y alone

If (Nx − My)/M is a function of y only, then

μ( y ) = exp( ∫ Nx − MyM dy )

μ depending on both

When neither ratio is a single-variable function, look for a product form μ = xa yb. The exponents a and b are chosen so that the exactness condition holds; this is a two-equation system in a and b, and one solution is enough.

The integrating factor is determined only up to a constant, so answers that differ by a multiplicative constant are equivalent.

Worked 3.1: integrating factor depending on x

Evaluate the integrating factor of (x² + y² + 3)dx − 2xy dy = 0.

Show solution
Step 1 — identify M and N
M = x² + y² + 3, N = −2xy
Step 2 — the exactness test
My = 2y, Nx = −2y ⇒ not exact
Step 3 — form the ratio (My − Nx)/N
2y − (−2y)−2xy = 4y−2xy = −2x
Step 4 — the result depends on x only, so μ is a function of x
μ = exp( ∫ −2/x dx ) = e−2 ln x = 1/x²
The answer −2/x is the ratio itself, not its exponential integral. The integrating factor is always μ = e∫(ratio); dropping the exponential is the standard error on this question type. Checking that the resulting equation is exact is a one-line verification.
Variables M, N — coefficients of dx and dy μ — integrating factor
Worked 3.2: integrating factor depending on y

Evaluate the integrating factor of (y⁴ + 2y)dx + (xy³ + 2y⁴ − 4x)dy = 0.

Show solution
Step 1 — identify M and N
M = y⁴ + 2y, N = x y³ + 2y⁴ − 4x
Step 2 — the exactness test
My = 4y³ + 2, Nx = y³ − 4
Step 3 — try the y-only ratio first
Nx − MyM = y³ − 4 − ( 4y³ + 2 )y⁴ + 2y = −3y³ − 6y ( y³ + 2 ) = −3y
Step 4 — the result depends on y only, so μ is a function of y
μ = exp( ∫ −3/y dy ) = e−3 ln y = 1/y³
The answer y³ is the reciprocal of the correct factor. The direction of the test determines which form of the ratio to use: (My − Nx)/N tests for μ(x); (Nx − My)/M tests for μ(y). Swapping them gives the reciprocal — which is still an integrating factor, but the answer does not match the expected option.
Variables M, N — coefficients of dx and dy μ — integrating factor

4. Applied Differential Equations

Five standard physical models cover the chapter, and each reduces to a separable or linear equation.

Population growth or decay

dP/dt = k P ⇒ P(t) = P0 ekt

Doubling time: t2 = ln 2 / k. Time to reach any multiple M: t = ln(M)/(k). The ratio tM/t2 = ln M / ln 2 — a handy mental check.

Newton's law of cooling

dT/dt = −k ( T − Ta ) ⇒ T(t) = Ta + ( T0 − Ta ) e−kt

The decay rate k is fixed by one measurement, then used to predict the time to any other temperature.

Falling body with resistance

dV/dt + 1τ V = g ⇒ V(t) = gτ ( 1 − e−t/τ )

The terminal velocity is gτ, and the time constant τ = 1/k, where k is the resistance coefficient per unit mass.

Torricelli's law

A(h) dhdt = −Cd a √( 2gh )

The tank cross-section A(h) depends on the shape (constant for a cylinder, proportional to h for a cone, proportional to 2Rh − h² for a hemisphere). The coefficient of discharge Cd is an experimental correction, typically 0.6 for a sharp-edged orifice, that accounts for the vena contracta and the real (non-ideal) flow. Without Cd, the calculation gives the ideal drain time; with it, the actual drain time.

Mixing (compartmental) problems

For a tank with volume V(t) receiving a stream of pollutant concentration Cin at rate qin and draining at qout:

dPdt = Cin qin − qoutV(t) P

with P the total pollutant mass (or volume). When V is constant, the equation is linear with constant coefficients; when V is changing, the coefficient qout/V(t) varies, and the integrating factor is exp(∫qout/V(t) dt).

Worked 4.3: Newton's law of cooling

Air temperature is 30°; a substance cools from 100° to 70° in 15 min. How long will it take to cool from 100° to 50°?

Show solution
Step 1 — write Newton's law in the standard integrated form
T(t) = Ta + ( T0 − Ta ) e−kt
Step 2 — find k from the 100° → 70° data over 15 min, with Ta = 30°
70 = 30 + ( 100 − 30 ) e−15k
40 = 70 e−15k ⇒ e−15k = 4/7
k = ln(7/4)15 = 0.559615 = 0.0373 min−1
Step 3 — solve for the time to reach 50°, starting from 100°
50 = 30 + 70 e−kt ⇒ e−kt = 20/70 = 2/7
t = ln(7/2)k = 1.25280.0373 = 33.6 min
The answer 33.59 min is the exact value; the key matches. The frequent error is to use the elapsed time (15 min) as the exponent rather than building the ratio from the temperature difference — the model's time variable is always the time from the starting temperature, not the time between observations.
Variables T — substance temperature, °C Ta = 30° — ambient temperature T0 = 100° — initial substance temperature k — cooling constant, min−1
