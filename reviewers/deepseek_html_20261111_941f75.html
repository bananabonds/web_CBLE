1. Combination and Permutation

Two questions decide every counting problem: does order matter? and is repetition allowed? The answers fix which formula applies.

Order matters?Repetition?Count
YesNonPr = n! / (n − r)!
YesYesnr
NoNonCr = n! / [ r! (n − r)! ]
NoYesn+r−1Cr

Conditional probability

The conditional probability of A given B is the ratio of the joint event to the conditioning event:

P( A | B ) = P( A ∩ B )P( B )

The denominator is the event that is known to have happened, not the total sample space. Restricting the sample space to B before counting is the whole idea.

Permutations with repeated items

For a word with n letters and repeats n1, n2, …, the number of distinct arrangements is

n!n1! n2! …

Circular permutations of n distinct objects give (n − 1)! arrangements. When the circular objects can be flipped (a keychain, a bracelet), each arrangement is counted twice, so the count halves to (n − 1)!/2.

Stars and bars

The number of ordered solutions to x1 + x2 + … + xk = n with each xi a non-negative integer is

n+k−1Ck−1

When each xi must be a positive integer, subtract k from n first:

n−1Ck−1
Worked 1.1: two children, given at least one boy

A couple has two children. Find the probability that both children are boys, given that at least one of the children is a boy.

Show solution
Step 1 — list the sample space for two children
S = { BB, BG, GB, GG }
Step 2 — the conditioning event B = "at least one boy" is the set
{ BB, BG, GB } ⇒ P( B ) = 3/4
Step 3 — the intersection A ∩ B = "both boys" is { BB }, with P = 1/4
Step 4 — apply the conditional formula
P( BB | B ) = 1/43/4 = 1/3
The answer 1/2 comes from treating the children as ordered and fixing the first as a boy — which is a different conditioning event (the older child is a boy, not at least one). The word "at least one" allows either child to be the boy, which includes BG and GB as distinct outcomes.
Variables S — sample space, {BB, BG, GB, GG} A — both children are boys B — at least one child is a boy
Worked 1.2: derangements of four persons

Persons A, B, C, D sit in four seats 1, 2, 3, 4 in this order. How many seating arrangements have none of the four persons in his original chair?

Show solution
Step 1 — this is a derangement of 4 items, written !4
Step 2 — apply the derangement recurrence !n = ( n−1 )( !(n−1) + !(n−2) ), with !1 = 0, !2 = 1
!3 = 2( !2 + !1 ) = 2( 1 + 0 ) = 2
!4 = 3( !3 + !2 ) = 3( 2 + 1 ) = 9
!4 = 9 arrangements
The derangement count 9 is much smaller than 4! = 24, because most permutations leave at least one person in his own chair. The recurrence is the fastest route; listing all 24 and striking out those with any fixed point gives the same answer but is error-prone.
Variables !n — number of derangements of n distinct objects (permutations with no fixed points) n — number of persons and seats, 4

Worked 1.4: stars and bars with non-negative integers

Find the number of ordered quadruples of non-negative integers (a, b, c, d) such that a + b + c + d = 12.

Show solution
Step 1 — this is a stars-and-bars problem: 12 stars to place into 4 bins, with empty bins allowed
n = 12 (total to distribute), k = 4 (bins)
Step 2 — apply the non-negative form
count = n+k−1Ck−1 = 12+4−1C4−1 = 15C3
Step 3 — evaluate
15C3 = 15 × 14 × 133 × 2 × 1 = 2 7306 = 455
The answer 445 comes from a slip in the binomial coefficient or from using a different stars-and-bars variant. The check is that 15C3 = 15C12; both give 455. The (n+k−1) form is the one for non-negative integer solutions; the (n−1) form is for positive integer solutions.
Variables a, b, c, d — the four unknowns, non-negative integers n — sum, 12 k — number of unknowns, 4
Worked 1.5: stars and bars with positive integers

Find the number of ordered triples of positive integers (a, b, c) such that a + b + c = 8.

Show solution
Step 1 — the variables are positive integers, not non-negative; substitute a′ = a − 1, b′ = b − 1, c′ = c − 1
a′ + b′ + c′ = 8 − 3 = 5 (with a′, b′, c′ ≥ 0)
Step 2 — apply the non-negative stars-and-bars form to the transformed problem
count = 5+3−1C3−1 = 7C2
Step 3 — evaluate
7C2 = 7 × 62 = 21
The answer 21 is the same as n−1Ck−1 = 7C2 — the positive-integer form of stars and bars. Using the non-negative form directly (without the substitution) would give 10C2 = 45, which counts solutions with zero (not allowed).
Variables a, b, c — the three unknowns, positive integers n — sum, 8 k — number of unknowns, 3

2. Series

A series is the sum of the terms of a sequence. Two families cover the chapter: arithmetic and geometric.

Arithmetic series

Sn = n2 [ 2a1 + ( n − 1 ) d ] = n2 ( a1 + an )

Geometric series

Sn = a1 rn − 1r − 1, S∞ = a11 − r ( |r| < 1 )

Binomial sums and the hockey stick identity

A series of binomial coefficients with a fixed lower index follows the hockey stick identity:

nΣi=r iCr = n+1Cr+1

The sum of a column in Pascal's triangle equals the entry one row below and one column right. The name comes from the shape of the entries in Pascal's triangle — the column plus the endpoint form a hockey stick.

The binomial theorem sums a whole row:

( a + b )n = Σk=0n nCk ak bn−k

Setting a = b = 1 gives the useful special case

Σk=0n nCk = 2n

which is the count of all subsets of an n-element set. Setting a = 1, b = −1 gives Σ (−1)k nCk = 0 for n ≥ 1.

Worked 2.1: the hockey stick identity

Which of the following is equivalent to 15C15 + 16C15 + 17C15 + … + 2023C15?

Show solution
Step 1 — write the sum in sigma notation with the fixed lower index visible
Σi=152023 iC15
Step 2 — apply the hockey stick identity with r = 15 and n = 2023
Σi=rn iCr = n+1Cr+1
= 2023+1C15+1
Step 3 — simplify
= 2024C16
The answer 2023C15 is the last term alone, not the sum. The identity says the sum of the whole column equals the next row's entry one column right; dropping the sum produces an answer that looks structurally similar but is off by the entire running total.

3. Probability Mass Function

A discrete random variable is described by its probability mass function, a rule that assigns a probability to each possible value. Three axioms define a valid PMF:

p(x) ≥ 0, Σx p(x) = 1, p(x) = 0 outside the support

For a continuous random variable the PMF is replaced by a probability density function f(x), which satisfies

f(x) ≥ 0, ∫−∞∞ f(x) dx = 1

The density is not a probability; probabilities are integrals of the density over intervals. This is why f(x) may exceed 1.

The normal distribution

f(x) = 1σ √(2π) e−(x−μ)²/(2σ²)

Probabilities are computed by standardizing and reading the standard normal CDF Φ(z):

z = x − μσ, P( a < X < b ) = Φ( zb ) − Φ( za )

Geometric probability

When a point is chosen uniformly from a region, the probability of any event is the ratio of areas. The bus problem is the standard example: two arrival times chosen uniformly in the same interval form a square of possible outcomes; the event "you catch the bus" is the strip of the square where the two time intervals overlap.

Worked 3.1: derangement of six hats

Suppose all six men at a party throw their hats into the centre of the room. Each man then randomly selects a hat. Find the probability that none of the six men selects his own hat.

Show solution
Step 1 — the number of men is n = 6; the favourable outcomes are derangements
favourable = !6
Step 2 — compute the derangement using the recurrence, or the closed approximation !n ≈ n!/e
!1 = 0, !2 = 1, !3 = 2, !4 = 9, !5 = 44, !6 = 265
Step 3 — the total number of arrangements is 6!
6! = 720
Step 4 — form the probability
P = 265720 = 53144 ≈ 0.368
P = 53/144
The answer 17/48 = 0.354 comes from the independent-events approximation (5/6)6 ≈ 0.335, which is close but not exact. The true probability approaches 1/e ≈ 0.368 as n grows — a good sanity check on any derangement result. The correct calculation requires the inclusion–exclusion count, not the product of independent probabilities.

Worked 3.2: geometric probability — the bus problem

You and the bus both arrive at a stop at random times between 12:00 and 13:00. The bus waits 5 minutes before leaving; you wait 20 minutes before leaving if the bus has not come. What is the probability that you catch the bus?

Show solution
Step 1 — let y be your arrival (minutes after 12:00) and b the bus arrival; both uniform on [0, 60]
y ∈ [0, 60], b ∈ [0, 60]
Step 2 — you are at the stop from y to y + 20; the bus is there from b to b + 5
Step 3 — you catch the bus exactly when the two intervals overlap
y ≤ b + 5 and b ≤ y + 20
y − 20 ≤ b ≤ y + 5
Step 4 — total area of the square of possible outcomes
60 × 60 = 3 600
Step 5 — area of the top miss region (b > y + 5): triangle with legs 55
12 ( 55 )² = 1 512.5
Step 6 — area of the bottom miss region (b < y − 20): triangle with legs 40
12 ( 40 )² = 800
Step 7 — favourable area and probability
favourable = 3 600 − 1 512.5 − 800 = 1 287.5
P = 1 287.53 600 = 103/288 ≈ 0.358
The answer 1/4 comes from treating the two waits as equal (symmetric). They are 5 and 20, and the asymmetry shows up in the different triangle legs 55 and 40. Sketching the strip in the 60×60 square before computing is the safeguard — the two miss triangles are different sizes, and each must be computed separately.

The average number of acres burned by forest fires in a New Mexico county is 4 300 per year, with a standard deviation of 750. The distribution is normal. Find P(2 500 < X < 4 200).

4. Central Tendency and Inference

Sample statistics estimate population parameters. The standard error of a sample mean quantifies how much the estimate would vary from sample to sample:

SE = σ√n (population σ known), s√n (sample s used)

z-statistic (population σ known)

z = x̄ − μσ/√n

t-statistic (population σ unknown)

t = x̄ − μs/√n, df = n − 1

Two-sample t-statistic

t = x̄₁ − x̄₂√( s₁²/n₁ + s₂²/n₂ )

Confidence intervals

CI = x̄ ± zα/2 σ√n (z known)
CI = x̄ ± tα/2, n−1 s√n (t unknown)

The multiplier comes from the sampling distribution. For 95 % two-sided with a large sample, z = 1.96. For a 95 % CI from a sample of size 30 using the sample standard deviation, t0.025, 29 ≈ 2.045 — slightly larger than 1.96, which is why the t-interval is slightly wider.

Percentiles and quartiles

The k-th percentile is the value below which k % of the data falls. Convention (one of several):

position = ( n + 1 ) · k100

A non-integer position is interpolated linearly between the two adjacent values. The 1st quartile is the 25th percentile, the median the 50th, and the 3rd quartile the 75th.

Worked 4.1: z-statistic for an IQ claim

A principal claims his students are above average intelligence. A random sample of 30 students has a mean IQ of 112.5. The population mean is 100, with σ = 15. Find the z-statistic.

Show solution
Step 1 — identify the values
x̄ = 112.5, μ = 100, σ = 15, n = 30
Step 2 — compute the standard error
SE = 15√30 = 155.477 = 2.739
Step 3 — form the z-statistic
z = 112.5 − 1002.739 = 12.52.739
z ≈ 4.56
The answer 2.56 usually comes from a slip in the standard error — either using σ/√30 with the wrong σ, or computing (112.5 − 100)/√30 = 2.28 then mis-labelling it. The correct denominator 2.739 is what makes the result 4.56. The value 4.56 is very large — an IQ 12.5 points above the mean in a sample of 30 is roughly 4.5 standard errors above what chance would produce.

Worked 4.2: t-based confidence interval

A sample of 30 test scores has a mean of 70 and a sample standard deviation of 10. Construct a 95 % confidence interval using t0.025, 29 = 2.045.

Show solution
Step 1 — identify the values
x̄ = 70, s = 10, n = 30, t = 2.045
Step 2 — compute the standard error
SE = s√n = 10√30 = 105.477 = 1.826
Step 3 — compute the margin of error
ME = t × SE = 2.045 × 1.826 = 3.734
Step 4 — write the interval
CI = 70 ± 3.73
The answer 70 ± 4.73 comes from a slip in the standard error (using s/√20 or s directly rather than s/√30). The margin of error is the product of the critical value and the standard error; each factor must be computed and written on its own line before multiplying.
Variables x̄ — sample mean, 70 s — sample standard deviation, 10 n — sample size, 30 t — critical t value, 2.045
Worked 4.3: z-based confidence interval with large n

The heights of 40 randomly chosen students have a mean of 175 cm. The population standard deviation is 20 cm. Find the 95 % confidence interval.

Show solution
Step 1 — the population σ is known, so this is a z-interval
x̄ = 175, σ = 20, n = 40, z0.025 = 1.96
Step 2 — compute the standard error
SE = 20√40 = 206.325 = 3.162
Step 3 — compute the margin of error
ME = 1.96 × 3.162 = 6.198
Step 4 — write the interval
CI = 175 ± 6.19
The answer 175 ± 3.56 comes from dropping the z multiplier (using only the SE = 3.16) — a factor-of-two error that makes the interval far too narrow. The whole point of a confidence interval is that it is wider than the standard error; the multiplier converts a point estimate into an interval estimate.
Variables x̄ — sample mean, 175 cm σ — population standard deviation, 20 cm n — sample size, 40 z — standard normal critical value, 1.96
Worked 4.4: two-sample t-statistic

Newborn weights from two hospitals: Hospital A has n = 20, mean 7.5 lb, s = 0.8; Hospital B has n = 20, mean 7.1 lb, s = 1.2. Compute the t-statistic.

Show solution
Step 1 — the two-sample t-statistic is
t = x̄₁ − x̄₂√( s₁²/n₁ + s₂²/n₂ )
Step 2 — compute each term under the root
s₁²n₁ = 0.6420 = 0.032
s₂²n₂ = 1.4420 = 0.072
Step 3 — sum and square root
√( 0.032 + 0.072 ) = √0.104 = 0.3225
Step 4 — form the t-statistic
t = 0.40.3225 = 1.24
The answer 2.24 usually comes from using the pooled-variance formula instead of the Welch formula — the pooled version (assuming equal variances) gives a slightly different denominator and a different result. The t-value of 1.24 is below the critical 2.024, so the null hypothesis of no difference is not rejected at the 5 % level with this small sample.
Variables x̄₁, x̄₂ — sample means, 7.5 and 7.1 s₁, s₂ — sample standard deviations, 0.8 and 1.2 n₁, n₂ — sample sizes, 20 each
Worked 4.5: 20th percentile and 1st quartile

For the data 3, 13, 11, 11, 5, 4, 2, find (a) the 20th percentile and (b) the 1st quartile.

Show solution
Step 1 — sort the data (n = 7 values)
2, 3, 4, 5, 11, 11, 13
Step 2 — (a) 20th percentile: use the (n+1) convention

Worked 4.6: two-sample t-test for instructional method

25 random students received in-person instruction (mean 80, s = 5); 25 random students received online instruction (mean 75, s = 7). Compute the t-statistic.

Show solution
Step 1 — apply the two-sample t-statistic
t = 80 − 75√( 25/25 + 49/25 )
Step 2 — compute each term under the root

Step 3 — sum and square root

5. F-Statistic (One-Way ANOVA)

Analysis of variance tests whether three or more group means differ. The total variability is split into between-treatments variability (attributable to the groups) and within-treatments variability (attributable to chance).

The sum of squares

SST = Σi,j ( xij − x̄̄ )² (total)
SSTR = n Σi ( x̄i − x̄̄ )² (between treatments)
SSE = Σi,j ( xij − x̄i )² (within)
SST = SSTR + SSE

The degrees of freedom

dfSSTR = k − 1 (k groups)
dfSSE = N − k (N total observations)
dfSST = N − 1

The mean squares and F-statistic

MSB = SSTRk − 1, MSE = SSEN − k
F = MSBMSE

The F-statistic is the ratio of between-group to within-group variance. If the groups truly have the same mean, F is near 1; if the between-group variance dominates, F is large and the null hypothesis (all means equal) is rejected.
